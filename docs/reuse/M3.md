## Decisions applied (owner, M3 addendum)

1. `t_class` is primary; the alignment output is an ordered candidate list; `t_exact` recorded.
2. Drift rule: `unreplayable` on any masked diff in a mutating prefix action or in an output
   the failed policy later quoted, and on any shell exit-code change; read-only diffs are
   warnings. Shell results are compared on stdout and stderr only (`duration_seconds` is never
   part of the comparison); injected-tool results on their content. Masks: ISO timestamps and dates, clock strings, epoch floats, endpoints/ports,
   temp paths, pids, `ls` mtimes, the workspace path.
3. Two arms, k = 3, first 5 candidates; sufficient iff substitute >= 2/3 and control <= 1/3
   (unscored rollouts count against sufficiency in both arms); none sufficient ->
   `oracle_step: unvalidated`. **Cost choice made here:** when the substitute arm is already
   below 2/3 the control arm cannot change the verdict and is skipped (`economize`, default);
   `--full-arms` runs it anyway.
4. Rule table R1 to R10; observability components `where_eligible: false`; the model picks
   among candidates only (`attribution: llm` when more than one candidate, else `rule`).
5. Distance = `same_layer` and `same_file` covariates; arms `corrupt_where_near` /
   `corrupt_where_far`; empty pool falls back to the other tier with `distance_fallback: true`.
6. Genuineness G1 to G4; `undetermined` is never an oracle; only `genuine` references align.
7. Placeholders `[path] [routine] [tool] [component] [setting] [layer]`; component ids win
   over same-named `harness.json` keys (`system_prompt`).
8. HarnessEvolve cited by section from https://arxiv.org/html/2609.00829v1.
